# StoryMaker AI

AI-генератор серии из 3 Instagram Stories для бизнеса. Пользователь заполняет форму (ниша, цель, стиль, доп. факты) — Gemini создаёт тексты, идеи визуала, интерактив и рекомендации по оформлению.

## Стек

- Next.js (App Router) + TypeScript + Tailwind CSS
- Google Gemini API (`@google/generative-ai`)
- Экспорт PDF: `jspdf` + `html2canvas`

## Быстрый старт

1. Установите зависимости:

```bash
npm install
```

2. Создайте файл **`.env.local`** в корне проекта (рядом с `package.json`).  
   Файл **`.env.example` Next.js не подхватывает** — нужен именно `.env.local`.

3. Вставьте ключ Gemini из [Google AI Studio](https://aistudio.google.com/apikey):

```env
GEMINI_API_KEY=ваш_ключ
```

   Без кавычек и пробелов вокруг `=`. После сохранения **перезапустите** dev-сервер (`Ctrl+C`, затем `npm run dev`). В терминале должно появиться: `Environments: .env.local`.

4. Запустите приложение:

```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Возможности

- Форма: ниша (включая свою), цель сторис, стиль текста, доп. информация
- Генерация 3 Stories через серверный API (ключ не попадает в браузер)
- 5 визуальных шаблонов карточек
- Светлая / тёмная тема
- Копирование текста одной сторис и всей серии
- Скачивание результата в PDF
- Повторная генерация, индикатор загрузки и обработка ошибок

## Важно

Модель не должна выдумывать цены, скидки и другие факты. Указывайте всё существенное в поле «Дополнительная информация».

## Если страница постоянно перезагружается / в терминале сыпятся `GET / 200`

1. **Перезапустите dev** после обновления кода: `Ctrl+C`, затем `npm run dev` (один процесс).
2. Откройте **одну** вкладку браузера; закройте Simple Browser / Preview в Cursor на localhost.
3. В проекте включено `agentRules: false` — иначе в Cursor `next dev` перезаписывает `AGENTS.md` и снова собирает проект.
4. Если не помогло, попробуйте стабильный режим: `npm run dev:webpack`.
5. На Windows добавьте папку проекта в исключения антivirus (Defender) — иначе Turbopack может бесконечно пересобирать файлы.
